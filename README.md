# BEXO Music Bot

بوت تيليجرام لمعالجة الملفات الصوتية والفيديو وإضافة الغلاف والبيانات الوصفية.

## المزايا
- تعديل الصوت وتحويله إلى MP3.
- استخراج الصوت من الفيديو.
- إنشاء أغنية كاملة: صوت + عنوان + فنان + غلاف.
- اختيار الجودة: 128 / 192 / 256 / 320 kbps.
- ضغط الملفات الكبيرة تلقائياً قبل الإرسال.
- إحصائيات للمستخدم ولوحة تحكم للمطور.
- تنظيف تلقائي للملفات المؤقتة.
- SQLite مع WAL وتحسينات بسيطة للأداء.
- Docker + Railway/أي VPS يدعم Docker.

## التشغيل
1. ثبّت Python 3.11 وFFmpeg.
2. انسخ `.env.example` إلى `.env`.
3. ضع `BOT_TOKEN` و`OWNER_ID` الصحيحين.
4. ثبّت المتطلبات:
   `pip install -r requirements.txt`
5. شغّل:
   `python main.py`

## مهم
لا ترفع ملف `.env` إلى GitHub أو إلى أي جهة أخرى. إذا ظهر توكن البوت في ملف تم مشاركته، قم بإلغائه وإنشاء توكن جديد من BotFather.

## ملاحظة الأزرار
Telegram لا يوفر API لتلوين أزرار ReplyKeyboard بلون مخصص. لذلك تم تحسين الشكل باستخدام رموز وألوان مرئية وترتيب واضح، بينما الأزرار الداخلية تستخدم InlineKeyboard.
